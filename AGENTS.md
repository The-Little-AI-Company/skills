# skills

## Git

- Follow the Git law in Jeff's `~/AGENTS.md` (2026-11-03). `prod` is the default branch and the finished product. All work happens on `dev`. Branch `task/<id>-<slug>` from `origin/dev`, open the PR into `dev`, never push or force-push `prod`, `main` or `dev`, and end every commit with `Task:`, `Agent:` and `Agent-Session:` trailers. `prod` changes only through a promotion PR from `dev`, and every merge waits for Jeff's approval.

Use [GitHub Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/github-flow/SKILL.md) for task PRs to `dev` and [Git Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/git-flow/SKILL.md) for promotions to `prod`. Install both complete skill folders, including their references, from personal source revision `649e340019a49f29d27bc940f0822d2c815dff8e`. On a managed host read the installed skills under `~/.agents/skills/`.

Use the [PR format](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/pr-template/SKILL.md), [review gate](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-gate/SKILL.md) and [review comments](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-comments/SKILL.md). Show Jeff the exact text and destination and wait for approval before posting or editing PR text or comments. Get approval for revised wording.
