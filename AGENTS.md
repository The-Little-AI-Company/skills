## Git

- Follow the Git law in Jeff's `~/AGENTS.md` (2026-11-03). `prod` is the default branch and the finished product. All work happens on `dev`. Branch `task/<id>-<slug>` from `origin/dev`, open the PR into `dev`, never push or force-push `prod`, `main` or `dev`, and end every commit with `Task:`, `Agent:` and `Agent-Session:` trailers. `prod` changes only through a promotion PR from `dev`, and Jeff approves each independently verified head before merge. Squash task PRs into `dev`, promote to `prod` with a merge commit, then sync `prod` back into `dev`.

Use [GitHub Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/github-flow/SKILL.md) for task PRs to `dev` and [Git Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/git-flow/SKILL.md) for promotions to `prod`. Use both complete skill folders, including their references, at personal source revision `649e340019a49f29d27bc940f0822d2c815dff8e`. On Jeff’s laptop use the existing Brain discovery links. On other hosts install from that exact revision. Check the installed files against the pin before use. Follow the GitHub Flow cleanup checks when the task branch has merged.

Use the [PR format](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/pr-template/SKILL.md), [review gate](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-gate/SKILL.md) and [review comments](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-comments/SKILL.md). Show Jeff the exact text and destination and wait for approval before posting or editing a PR title, body, review, reply or comment. Get fresh approval if the wording or destination changes.
