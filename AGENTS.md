## Git

- Follow the Git law in Jeff's `~/AGENTS.md` (2026-11-03). `prod` is the default branch and the finished product. All work happens on `dev`. Branch `task/<id>-<slug>` from `origin/dev`, open the PR into `dev`, never push or force-push `prod`, `main` or `dev`, and end every commit with `Task:`, `Agent:` and `Agent-Session:` trailers. `prod` changes only through a promotion PR from `dev`, and every merge waits for Jeff's approval.

Use `github-flow/SKILL.md` for task PRs and `git-flow/SKILL.md` for promotions. Paths start at the root of the [personal GitHub skills source](https://github.com/Jeff-Kazzee/github-skills). On a managed host read them under `~/.agents/skills/`. Elsewhere install both complete folders from a reviewed source revision containing them. The company catalogue references the personal skills and keeps its existing packages.

Use the [PR format](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/pr-template/SKILL.md), [review gate](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-gate/SKILL.md) and [review comments](https://github.com/Jeff-Kazzee/github-skills/blob/8ce6fda01a1cca24b20a406e3efd8f087bf70264/review-comments/SKILL.md). Show Jeff the exact text and destination before posting or editing PR text or comments. Get approval for revised wording.
