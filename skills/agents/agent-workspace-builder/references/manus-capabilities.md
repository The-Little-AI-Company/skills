# Manus capability map and execution coverage

## Read this map correctly

Baseline: October 3, 2026, including Manus 2.0, Flex, Video Editor, and Game Dev releases. Each row links a primary source, a Manus entry point, an the target workspace implementation route, and an acceptance gate. The linked execution guides carry detailed procedures. Refresh UI labels and provider details against current sources before use.

All catalog entries start **documented**, with live verification false. This is research coverage, not evidence that the user's installation supports 60 capabilities. Inspect the actual host before claiming foundations exist. Agent teams, studio editors, providers, and durable workflows require real implementation and configuration.

## Product boundaries and documented uncertainty

- Manus Studio's recent editable video/game tooling extends the older generic multimedia docs. Prefer feature-specific release material for that behavior.
- Cue is a separate app described in the 2.0 announcement. Its identities, telephony, wallet, and group-agent behavior are adjacent coverage, not native Manus/the target workspace functionality.
- Manus's API and its UI have different surfaces. The reviewed API introduction identifies v2; verify individual endpoints before use.
- Manus's website infrastructure and partner-specific payment setup are services. A skill must connect or build equivalents, not claim to inherit those entitlements.
- Some docs contain outdated model tables, vague availability language, or conflicting notes. Do not preserve “latest” model claims, prices, plan limits, or performance claims without rechecking.
- The meeting-minutes page contains inconsistent pause/resume wording. Treat exact capture behavior as requiring current product verification.
- Manus's older context-engineering article is design history. Its cache/tool strategies are useful ideas, not a public specification of Cascade.
- “Complete” means the declared requested set passes end-to-end checks. New releases and account-specific features require a renewed audit.
